# AskMe 
## ДЗ1
Реализована статическая верстка сайта для вопросов и ответов с использованием HTML и CSS.

## Как открыть проект
На данный момент есть статические HTML-файлы, которые не требуют установки дополнительного ПО или серверов.

1. Скачайте репозиторий.
2. Перейдите в папку `public/`.
3. Откройте файл `index.html` в любом браузере.

## Реализованные страницы
В папке `public/` находятся страницы:
- `index.html` — Главная страница
- `question.html` — Страница одного вопроса с ответами
- `ask.html` — Форма создания вопроса
- `login.html` — Форма входа
- `signup.html` — Форма регистрации
- `profile.html` — Страница профиля пользователя
- `base.html` — Шаблон-каркас для всех страниц

## Структура проекта
- `public/` — верстка
- `public/static/css/` — стили
- `public/static/img/` — аватарки
