## Реализованные страницы
- `/` - Главная страница (список новых вопросов)
- `/hot/` — Список лучших вопросов
- `/tag/<tag_name>/` — Список вопросов по конкретному тегу
- `/question/<id>/` — Страница одного вопроса с ответами
- `/ask/` — Форма создания нового вопроса
- `/login/` — Форма входа
- `/signup/` — Форма регистрации
- `/profile/` — Страница редактирования профиля

## Запуск проекта локально:

1. Сначала скопируйте репозиторий на свой компьютер:
   ```bash
   git clone <ссылка на репозиторий>
   ```

2. Перейдите в корень проекта:
   ```bash
   cd ./2026-VK-EDU-Web-13-Leontev-A
   ```

3. Соберите докер контейнер:
   ```bash
   docker-compose build
   ```

4. Запустите контейнер:
   ```bash
   docker-compose up
   ```

5. Перейдите по ссылке:
   ```bash
   http://localhost:8000/
   ```
